# Portfólio — Heitor Serra Neto (V7)

Site estático pronto para GitHub Pages.

## Publicar
1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css`, `script.js` e a pasta `assets` para a raiz.
3. No GitHub: Settings → Pages → Deploy from a branch → `main` / root.
